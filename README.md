# Hardware-Attested AI Agent Runtime — Public Portfolio

## Overview
A security engineering showcase exploring bounded, hardware-attested execution for AI-agent workloads. This public edition describes goals, evidence boundaries, and professional capabilities; it does not publish product implementation.

## Areas of work
- Confidential computing and attestation-aware authorization
- Security boundaries for AI-assisted operations
- Auditability, recovery considerations, and evidence discipline
- Evaluation of runtime governance in a bounded prototype

## Evidence and limitations
Historical evaluation materials and public commitments are retained as context, not as independent verification of production security. Private evidence and implementations are not distributed. No production certification, independently reproduced result, or turnkey deployment is claimed.

Related work includes VLADS Future V9 governance, Universal Browser Agent, Operator Studio, Forecast Intelligence, and R22 Scanner. These references describe areas of engineering activity, not released implementations.
