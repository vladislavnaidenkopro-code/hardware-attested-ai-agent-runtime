# Security Policy

This repository is a public-safe technical showcase. It intentionally excludes private source code, credentials, raw CloudTrail logs, AWS account/resource identifiers, internal IAM/KMS policy details, customer data and private deployment/recovery runbooks.

## Reporting

Do not publish credentials, personal data, third-party secrets or exploit material in public issues. Reports should stay within systems you own or are explicitly authorized to test.

## Scope of this repository

The repository contains documentation, public cryptographic commitments and a local manifest verifier. It is not the production implementation and should not be treated as a deployable security product.
