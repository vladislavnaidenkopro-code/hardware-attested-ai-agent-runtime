# Security and Disclosure

This repository is a public portfolio summary, not a deployable product or security certification. It excludes private source, credentials, sensitive operational data, implementation details, and internal runbooks.

## Responsible reporting
Do not post credentials, personal data, or sensitive security findings in public issues. Test only systems you own or are authorized to assess.

## Scope
No runnable verifier or private evidence is distributed in the current working-tree edition. Earlier Git history may contain additional public material and must be assessed separately.
