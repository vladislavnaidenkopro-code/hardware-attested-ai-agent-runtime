# Publication Checklist

Before making this repository public or linking it from LinkedIn:

- secret scan is clean;
- repository has fresh standalone Git history;
- no private Git objects or copied `.git` folders;
- no AWS account IDs, ARNs, IPs, access keys or resource identifiers;
- no raw CloudTrail logs or internal IAM/KMS policies;
- no private source implementation;
- claims match the release binding and non-claims;
- publication is treated as irreversible.
