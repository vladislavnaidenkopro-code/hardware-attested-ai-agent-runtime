# LinkedIn Project Text — V8.0

## Project name

Hardware-Attested AI Agent Runtime

## Short description

Built a hardware-backed proof for verifiable AI-agent execution using AWS Nitro Enclaves, KMS attestation and CloudTrail integrity validation.

## Description

Developed a confidential-computing proof for critical AI-agent operations where access to sensitive cryptographic material is bound to a measured enclave workload rather than to the parent host alone.

The system demonstrates measurement-bound secret access, negative and positive attestation tests, enclave-only plaintext handling, provider-side audit evidence, signed CloudTrail digest validation and exact event membership in a verified audit log.

This project is positioned as a foundation for secure AI-agent workflows, runtime governance and verifiable execution in enterprise environments.
